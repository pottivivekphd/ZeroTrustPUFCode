INSTALL MINICONDA (DATA SCIENCE PLATFORM)
Step 1: Download Miniconda 
1.	Visit 👉 https://www.anaconda.com/download
2.	Scroll down to Miniconda Installer
3.	Select Windows
4.	Download 64-Bit Graphical Installer
Step 2: Run Miniconda Installer
1.	Double-click Miniconda installer
2.	Click Next
3.	Click I Agree
Step 3: Installation Type
Choose: Just Me (Recommended)
Click Next
Step 4: Installation Location
Leave default:
C:\Users\YourName\Miniconda3
Click Next
Click Install
Step 5: Finish Installation
1.	Click Next
2.	Uncheck tutorials (optional)
3.	Click Finish
🎉 Miniconda installed successfully

INSTALL PYTHON (IN MINICONDA)  
Step 6: Create Python Environment and Install Python
1.	Open Miniconda 
2.	Type Conda create –name <myenv> python==3.12 (<myenv> choose name for your python environment )
3.	Type Y (For necessary package to install Python)
🎉 Python installed successfully
Step 7: Activate Python 
1.	Type Conda activate <myenv>

SET PYTHON ENVIRONMENT IN SPYDER
1.	Double click Spyder 
2.	Click Tool -> Preferences -> Python Interpreter
3.	Select Use the following Python Interpreter 
4.	Click Arrow Near Box and C:\Users\YourName\Miniconda3\ <myenv>
🎉 Finished
